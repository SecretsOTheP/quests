Plane of Knowledge library: Gork and Mork

Prerequisite: deploy server PR SecretsOTheP/EQMacEmu#483, containing the safe
  eq.create_npc_from_table(definition, x, y, z, heading)
API. The original eq.create_npc on older binaries is unsafe; the encounter refuses
automatic setup when the new API is unavailable and logs a server-update message.
A quest merge/reload alone cannot install that C++ prerequisite.

Once the server prerequisite is deployed:
1. Deploy this quest revision through the normal quests update process.
2. Restart/reload Plane of Knowledge, or use #reload quest in an already loaded
   PoK zone. The encounter starts from poknowledge/script_init.lua.
3. Allow up to six seconds. Gork and Mork are created automatically in memory,
   without manual SQL, a template NPC, or database NPC/spawn rows.

Gork, Theoretical Physicist: XYZ 949,25,3.4, heading 157. Say up.
Mork, Applied Physicist: XYZ 948,44,389.4, heading 157. Say down.
Up arrival: XYZ 948,36,389.4, heading 157.
Down arrival: XYZ 949,17,3.4, heading 157.
Mork wears a plate helmet. Roles are in their names for Zeal nameplates.

Hail, physics and plans produce private replies to the requesting player.
[UP] and [DOWN] are plain text: type the word without brackets. No clickable
links or public NPC speech. Only the requesting player moves, within a 100-unit
three-dimensional interaction range. Items and money are returned quietly.
The original elevator/buttons are untouched.

The encounter keeps one Gork and one Mork, recreates missing NPCs within five
seconds, and adopts its own existing entities after a quest reload. Older SQL
prototype NPCs at IDs 7151301/7151302 are replaced in memory; their recognized
loaded spawnpoints are disabled in memory only. No SQL rows are deleted or
updated. Reload/repop repeats reconciliation. Unrelated NPCs at either ID stop
setup for that ID and produce a diagnostic instead of being replaced.
The two empty named scripts prevent generic hand-in fallback for legacy SQL
installations; dialogue lives in lua_modules/library_gork.lua and library_mork.lua
and is registered by the encounter. Keep the complete file set together.

Focused checks with Lua 5.1, from the repository root:
  lua tests/pok_library_teleports_test.lua .
  lua tests/pok_library_setup_test.lua .

In-game verification after the new binary is installed:
- Hail Gork, say up; hail Mork, say down. Confirm both landings and private text.
- #reload quest: verify one of each remains and both still work.
- On TEST, untargeted #repop: verify one of each returns within five seconds.
- Unload/reload PoK once: verify automatic setup and travel again.
The earlier SQL-backed teleport test does not replace this new lifecycle test.
